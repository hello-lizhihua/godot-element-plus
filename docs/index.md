# godot-element-plus 组件库

godot-element-plus 是 Godot 通用 UI 组件库，GDScript 实现，独立仓库，经符号链接被项目引用。组件视觉风格为深色半透面板 + #f0ede6 米白文字 + #ffcc33 琥珀强调色，程序化绘制，圆角 6-14。

## 安装接入

```gdscript
# 接入后在任意场景脚本中使用滑块组件
var slider := preload("res://addons/godot-element-plus/slider/slider.gd").new()
add_child(slider)
```
